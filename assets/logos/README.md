# Logos BADBEAR.MED

Estructura oficial de identidad visual del proyecto.

- `principal/`: logo maestro BADBEAR.MED.
- `cursos/<curso>/`: variantes específicas de cada curso.

Convención recomendada dentro de cada carpeta de curso:

- `logo.png`: logo principal del curso, preferiblemente PNG con fondo transparente.
- `watermark.png`: versión para sello de agua grande de fondo.
- `icon.png`: versión simplificada/cuadrada para tarjetas, pestañas o accesos.

Los logos de curso deben conservar la huella + cabeza de panda como identidad base y adaptar el elemento médico al curso correspondiente.
