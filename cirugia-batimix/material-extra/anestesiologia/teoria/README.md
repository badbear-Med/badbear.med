# Material extra · Anestesiología · Teoría

Esta carpeta recibe los documentos complementarios originales de las cuatro clases de teoría, para enlazarlos en **Unidad 2 → Anestesiología → Teoría → Material extra**.

| Código | Clase | Archivo de referencia |

Los documentos originales **todavía no están cargados**. Los nombres anteriores solo sirven para identificarlos.

Cuando se reciban, conservar el formato de origen, o convertir a PDF solo si se solicita. Registrar cada ruta verificada en `cirugia-batimix/anestesiologia-datos.js`, campo `recursos.extra`, por ejemplo `/cirugia-batimix/material-extra/anestesiologia/teoria/nombre-verificado.pdf`.

Los otros recursos (PPT de clase, audio y video YouTube) se vinculan por separado en el mismo archivo de datos.
