TESIS I · CLASE 07

Plan de recolección de datos

Cómo convertir variables en datos confiables mediante técnicas, instrumentos, codificación, prueba piloto y preparación de la base de datos.

PROYECTO GUÍA BADBEAR.MEDFACTORES DE RIESGO CLÍNICOS Y METABÓLICOS ASOCIADOS A LA PROGRESIÓN DE PREDIABETES A DIABETES MELLITUS TIPO 2 Y EL IMPACTO DE UNA INTERVENCIÓN DE SEGUIMIENTO MÉDICO EN PACIENTES ATENDIDOS EN EL HOSPITAL NACIONAL HIPÓLITO UNANUE DEL 2022 - 2026

1. ¿Qué es recolectar datos?

Recolectar datos equivale a medir. El plan debe especificar qué se mide, cómo se mide, con qué instrumento, cómo se aplica y cómo se prepararán los datos para el análisis.

APLICACIÓN AL PROYECTO GUÍASe debe definir cómo se obtendrán HbA1c, glucosa, IMC, presión arterial, antecedentes clínicos, seguimiento médico y progresión a DM2 a partir de historias clínicas, registros o instrumentos previstos.

2. Técnicas e instrumentos

El material incluye encuesta, entrevista, análisis documental, observación experimental y no experimental. Los instrumentos pueden ser cuestionarios, escalas, pruebas estandarizadas, fichas de registro o guías de observación.

APLICACIÓN AL PROYECTO GUÍASi el proyecto utiliza historias clínicas, una técnica central será el análisis documental y el instrumento puede ser una ficha estructurada de recolección de datos.

3. Confiabilidad, validez y objetividad

Confiabilidad es la consistencia de los resultados; validez es el grado en que el instrumento mide la variable que pretende medir; objetividad se relaciona con la reducción de sesgos de quien administra, califica o interpreta.

APLICACIÓN AL PROYECTO GUÍALa ficha debe contener criterios uniformes para clasificar progresión y factores metabólicos, evitando que dos revisores interpreten de manera distinta el mismo dato.

4. Construcción y prueba piloto

El proceso incluye listar variables, revisar definiciones conceptuales, establecer definiciones operacionales, elegir o construir el instrumento, definir niveles de medición, codificar y realizar una prueba piloto para corregir problemas.

APLICACIÓN AL PROYECTO GUÍAAntes de revisar toda la población, se puede probar la ficha en un pequeño conjunto de registros para detectar variables ausentes, categorías ambiguas o dificultades de codificación.

5. Codificación y matriz de datos

Las respuestas o registros se codifican y se transfieren a una matriz de datos. Esta matriz debe corresponder directamente con la matriz de variables.

APLICACIÓN AL PROYECTO GUÍAEjemplo de codificación: progresión DM2: 0=no, 1=sí; seguimiento: 0=no, 1=sí; HbA1c: valor numérico; IMC: valor numérico y, si se requiere, una categoría adicional.

6. Análisis de datos

El material organiza el análisis en estadística descriptiva, evaluación de confiabilidad cuando corresponde y pruebas inferenciales para contrastar hipótesis. La elección de cada prueba depende del tipo de variable y del diseño.

BADBEAR.MED FIJA:La base de datos se diseña antes de recolectar masivamente; no después.
ERRORES A EVITAR
  • Recolectar datos que no corresponden a ningún objetivo.
  • Crear categorías sin definición previa.
  • Usar una ficha sin prueba piloto cuando es nueva o adaptada.
  • Confundir técnica de recolección con instrumento.

Cómo usar esta clase

Primero entiende el concepto. Después revisa cómo se aplica al proyecto guía. Finalmente comprueba que esa parte sea coherente con el resto del protocolo.

Regla del cursoLos ejemplos de todas las clases se construyen sobre el mismo proyecto de prediabetes → diabetes mellitus tipo 2.
