TESIS I · CLASE 13

Aspectos administrativos del plan de tesis

Cómo organizar cronograma, recursos, presupuesto y financiamiento para que el proyecto sea realmente ejecutable.

PROYECTO GUÍA BADBEAR.MEDFACTORES DE RIESGO CLÍNICOS Y METABÓLICOS ASOCIADOS A LA PROGRESIÓN DE PREDIABETES A DIABETES MELLITUS TIPO 2 Y EL IMPACTO DE UNA INTERVENCIÓN DE SEGUIMIENTO MÉDICO EN PACIENTES ATENDIDOS EN EL HOSPITAL NACIONAL HIPÓLITO UNANUE DEL 2022 - 2026

1. Función de los aspectos administrativos

Comprenden la planificación y gestión de actividades, plazos, recursos y costos necesarios para ejecutar el proyecto.

APLICACIÓN AL PROYECTO GUÍAEl proyecto 2022–2026 puede requerir etapas de permisos, depuración de registros, elaboración de base de datos, revisión de historias, análisis, redacción y difusión.

2. Cronograma de actividades

El cronograma establece inicio y finalización de cada actividad, ordena dependencias y ayuda a controlar plazos. El material propone el uso de diagramas de Gantt.

APLICACIÓN AL PROYECTO GUÍAEjemplo de secuencia: aprobación del protocolo → preparación de ficha → identificación de población → recolección de variables → control de calidad → análisis → redacción → presentación.

3. Presupuesto

Debe incluir recursos humanos, materiales y financieros: equipos, instrumentos, materiales, software, movilidad, servicios externos y otros gastos reales.

APLICACIÓN AL PROYECTO GUÍAPosibles rubros: acceso o digitalización de registros, almacenamiento seguro, software estadístico si tuviera costo, impresiones, movilidad institucional y apoyo para digitación o control de calidad cuando corresponda.

4. Recursos humanos y materiales

Los recursos humanos pueden incluir investigador, asesor, colaboradores y personal de apoyo. Los materiales comprenden equipos, instrumentos, insumos y software necesarios.

APLICACIÓN AL PROYECTO GUÍAAunque un recurso ya sea propiedad del investigador —por ejemplo, una laptop— debe reconocerse como parte de los recursos utilizados si la normativa del formato así lo solicita.

5. Financiamiento

Puede provenir del propio tesista, fondos institucionales, becas, subvenciones u otras fuentes. Debe declararse con transparencia.

APLICACIÓN AL PROYECTO GUÍASi todo el proyecto es autofinanciado, se declara. Si el hospital o universidad aporta acceso, infraestructura o software, conviene distinguir apoyo en especie de financiamiento monetario cuando el formato lo permita.

6. Coherencia administrativa

El cronograma y presupuesto deben ser compatibles con el método. Una actividad metodológica que requiere tiempo o recursos no puede desaparecer de la planificación administrativa.

BADBEAR.MED FIJA:Método, cronograma y presupuesto describen el mismo estudio desde tres perspectivas distintas.
ERRORES A EVITAR
  • Poner fechas incompatibles con los permisos o fases del estudio.
  • Presupuesto genérico sin relación con las actividades.
  • Declarar “costo cero” cuando existen recursos utilizados.
  • Olvidar contingencias o control de calidad.

Cómo usar esta clase

Primero entiende el concepto. Después revisa cómo se aplica al proyecto guía. Finalmente comprueba que esa parte sea coherente con el resto del protocolo.

Regla del cursoLos ejemplos de todas las clases se construyen sobre el mismo proyecto de prediabetes → diabetes mellitus tipo 2.
