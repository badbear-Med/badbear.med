Subir notas de un curso

Sube la lista de este curso con Código, Apellidos y Nombres, Nota. También se aceptan Código + Nota (si ya figura en el padrón) o Apellidos y Nombres + Nota (cuando haya una coincidencia única). La vista previa siempre mostrará código, nombre completo y nota. Para códigos nuevos es obligatorio proporcionar el nombre completo; las coincidencias ambiguas se bloquean. No se publicará nada hasta tu confirmación.

Al confirmar, las notas quedan visibles para el alumno autenticado cuando solicite consultarlas. No se envía ningún correo.

Opciones avanzadas · Archivo tradicional de resultados

Publicar una lista

Carga un archivo CSV UTF-8 con estas columnas: codigo, nombre, curso, periodo, evaluacion, nota, fecha. Desde Excel, utiliza «Guardar como → CSV UTF-8». Cada fila corresponde a una evaluación de un alumno. Máximo: 200 filas por carga; notas de 0 a 20, NSP (No se presentó) o LF (Límite de faltas); fecha AAAA-MM-DD. Conserva los códigos como texto para mantener los ceros iniciales.

Opciones avanzadas · Correos registrados

Correos de los alumnos

Carga una lista privada con las columnas codigo, correo. Publica primero los alumnos con sus resultados. Usa los correos que hayas confirmado con cada alumno: recibirán allí los enlaces de activación y recuperación. Guardar esta lista no envía mensajes.

Descargar plantilla de correos

Comparte el enlace público de BADBEAR.CAMPUS con la clase. Cada alumno pulsa «Activa o recupera tu cuenta por correo» e introduce su código. El mensaje contiene un enlace de un solo uso, válido por 30 minutos. Las notas se consultan dentro del portal.

Opciones avanzadas · Activación de alumnos

Acceso de los alumnos

Recuperación manual para alumnos sin correo

Si un alumno no puede recibir correo, verifica su identidad, selecciónalo y genera un código de activación o recuperación. Entrégaselo de forma individual. Vence en 24 horas y solo se puede utilizar una vez.

El alumno ingresa a BADBEAR.CAMPUS, abre «Activa tu cuenta» y escribe su código de alumno, este código de activación y la contraseña que desea crear.
