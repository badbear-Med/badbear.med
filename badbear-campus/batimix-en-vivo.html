Sala piloto con Jitsi JaaS. Prueba la cámara, el micrófono y la presentación desde esta página.

Entrar a la sala de prueba

Usa el mismo nombre de sala y la misma cuenta JaaS para los dos participantes. Cada uno entra con su propio token temporal.

Empieza con una letra o número. También puedes usar guiones y guiones bajos.
Usa el JWT generado para pruebas. El token se usa para conectar con JaaS y se borra del formulario al enviarlo.

Ingresa tus datos de prueba para abrir Jitsi.

Prueba con dos participantes

  1. En JaaS Console añade una clave en API Keys si tu cuenta todavía no tiene una. Usa JWT Generator para obtener un token temporal de anfitrión con permiso de moderador. Pega en el aula únicamente el JWT temporal. Guarda la clave privada fuera de la web.
  2. Genera un segundo token para el invitado, con otro identificador de usuario y sin el permiso de moderador. Ambos deben autorizar el mismo nombre de sala.
  3. Entra desde dos dispositivos o perfiles de navegador. Desde la computadora del anfitrión, elige Compartir pantalla en Jitsi y verifica en el otro dispositivo que se vea la presentación.
