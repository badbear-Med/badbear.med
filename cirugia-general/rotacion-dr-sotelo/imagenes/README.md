# Imágenes de apoyo

Las seis imágenes JPG se extraen del PDF aportado por el usuario `documentos/temas-exposicion-original.pdf`. No se atribuyen a una serie clínica ni se utilizan para establecer diagnósticos de pacientes. El PDF no documenta la procedencia clínica original de las imágenes; los pies de figura explican el uso docente y sus límites.
